# TabForge 0.9.11

- Fretboard previews stop animating when playback pauses or stops. Preview notes stay visible.
- The arrangement reuses its bar timing during playback. Opening songs and preparing audio transport no longer build unused MIDI events.
- Unused fretboard textures can be reclaimed, and the audio engine allocates fewer scratch buffers.
- Save updates an opened modern Guitar Pro `.gp` file directly. Save As opens the file picker for a different name, location, or format.
