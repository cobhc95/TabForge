# TabForge 0.9.11

Stable release. Playback is much lighter and smoother: about half the CPU, close to your screen's refresh rate, and far fewer stutters. Supersedes 0.9.10.

## ⚡ Playback performance

- **About half the CPU while a song plays:** measured on a 4K 140 Hz screen with the demo song, from about 5.3% to about 2.9% of the processor in Task Manager.
- **Smoother, display-rate playback:** about 136 frames a second instead of 60 to 90, with frames slower than 20 ms down from hundreds to a handful per 20 seconds.
- **Score and timeline kept ready on the graphics card:** the page and the timeline are drawn once and reused, instead of being redrawn on every frame. Text and notation look exactly as before.
- **Less repainting between the two playheads:** the timeline playhead moves when it has moved a pixel, or with the meters, so the window no longer repaints everything between it and the score's playhead on every frame.
- **Lighter playback bookkeeping:** the song's bar order is no longer rechecked note by note on every frame, and the timeline reuses its bar timing.
- **Calmer fretboards:** the fretboard keeps its still board and labels ready, rebuilds only when a note starts or stops, and rests when playback stops or pauses.
- **Score highlighting redraws only the bars that change.**
- **Less memory:** about 25–30 MB less, because the Composer panel's drum grooves are built the first time you open it, plus smaller buffers for tracks without effects and for MIDI logging, and fretboard textures freed after you switch looks.

## 🔧 Changed

- **Setup installs for all users:** Windows Setup now always installs to Program Files for everyone on the PC, with one administrator prompt and no per-user choice. A copy you installed earlier for your account only stays where it is; uninstall it from Windows Settings if you no longer want it.
- **TuxGuitar files:** Setup and Settings > Windows integration can also make TabForge open TuxGuitar (.tg) files.
- **Safer upgrades:** Setup closes a running TabForge through its normal close flow, so you can save your edits first.

## 🛠️ Fixes

- **Saving modern Guitar Pro files:** Save and Ctrl+S now write a reopened `.gp` file in place. Save As still opens the file picker.
- **Diagnostics:** playback start timing (snapshot, compile and first sound) appears in the playback trace, and an internal memory probe counts empty note collections for future memory work.

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental.
