# TabForge 0.9.10

Stable bug-fix release. Supersedes 0.9.9 with a playback fix for count-in.

## 🛠️ Fixes

- **First note after a count-in:** with count-in on, resuming a paused song or moving the playhead no longer skips the first note. The count-in now starts exactly where the music stopped.

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental.
