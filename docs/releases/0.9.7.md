# TabForge 0.9.7

Stable release. TabForge is now GPL-3.0-or-later. Guitar Pro Mix Tables play as Guitar Pro plays them, from the first beat on, and the Mix Table has a tab per track. GM sound no longer doubles a VST instrument. Keyboard mode can play the whole track, and Guitar Pro files open about 31% faster.

## 🎸 New since 0.9.6

- **Mix Table tabs per track:** one tab for each track that changes at the beat (red dot), plus the track you opened it from (hollow dot when it has no change). It opens on that track's tab. Each tab has its own instrument, volume, pan, effects, transition and All tracks; the shared tempo sits below the tabs. ‹ ›, the mouse wheel and the ▾ list reach tabs that don't fit. Tabs carry their track's colour, and the selected one is shaded with it. Unchanged values show what the track plays at that point, a drum track shows its drum kit, and Clear removes only the selected track's change.
- **Keyboard mode, Hear track:** a new toggle, off by default. Turn it on to hear the practised track's own notes as well as the ones you play.

## 🔧 Changed

- **Licence:** TabForge is now under the GNU General Public License, version 3 or any later version, instead of MIT. It stays free to use, share and change; anyone who distributes it or a modified version must share the source under the same licence. 0.9.6 and earlier stay available under MIT, and bundled components keep their own licences.
- **Matching dialog buttons:** OK, Cancel, Apply and Close share one width, padding and gap in about 25 windows, and the main button has the accent look and answers Enter.
- **Light theme:** OK and Apply are a darker blue, so their text is easy to read.
- **Your own shortcuts everywhere:** the piano roll's right-click menu, the Legato tooltip and the timeline's "Clear loop" tooltip show your bindings, not the defaults.
- **Faster Guitar Pro import:** about 31% faster (Master of Puppets 1.5 s → 1.1 s), with 27% to 40% less memory allocated while opening.
- **Tidier code, same sound:** dead code and stale docs removed; captions, fixed keys, dialog buttons, sizes and colours each come from one shared list; shared helpers replace about 160 copied MIDI clamps; new guards stop hard-coded hotkeys, captions and shapes; new opt-in speed and stress tests.

## 🛠️ Fixes

- **GM sound with a VST instrument:** GM could play alongside an instrument, mostly when a song opened and auto-loaded it. GM now turns off whenever an instrument plays and on when none does, and your own tick or untick always wins and is saved.
- **First-beat Mix Table:** it was ignored, so No More Lies started on distortion instead of clean guitar (424 tracks across the samples were affected). It now sets each track's starting sound, keeps only real changes, and shows its red timeline button on bar 1.
- **Wrong track in the Mix Table:** opening it from one track could show another track's change (the Bass at bar 50 showed Guitar 1's Distortion Guitar).
- **Guitar Pro 3 transitions and effects:** GP3 fades played as sudden drops, and chorus, reverb, phaser, tremolo and tempo-change lengths were lost.
- **Drum kit in the Mix Table:** a drum track's kit read as "1 - Grand Piano".
- **Readability:** the plug-in preset dialog's OK caption and the light-theme prompt text are back above 4.5:1 contrast.
- **Test reliability:** two playback tests that failed now and then under load wait for the engine properly (the engine was already correct).

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental.
