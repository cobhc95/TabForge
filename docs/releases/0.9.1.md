# TabForge 0.9.1

Stable release. It adds more rebindable shortcuts, fretboard note colours and a Fretboard settings page, a hand pointer on the fretboard capo, and scrolling while you drag a selection, and it fixes a loud first sound at start-up, a start-up crash and several plug-in editor and rewind problems. It supersedes 0.9.0.

## 🎸 New since 0.9.0

- **More shortcuts:** the piano roll's five tools, Quantize, Mute, Transpose, Zoom to fit, Legato, Duplicate and Invert can be rebound in Settings > Shortcuts, and so can Metronome, Count-in and Loop settings, Loop selected bars, Clear loop, Clear selection, Show / hide master track and Fretboard settings. One key can now serve commands that work in different places.
- **Fretboard note colours:** pick the Now, Next and Upcoming colours and a Fill or Ring dot style in Fretboard settings or in Settings > Fretboard & Keyboard, with the same colour picker as Appearance. Each legend row is clickable and opens the picker.
- **Capo pointer:** the fretboard's capo shows the Windows hand when you hover it and keeps it while you drag, so it is clear it can be moved.
- **Drag selection scrolls the view:** dragging a selection past the edge of the score, the timeline or the piano roll keeps scrolling, faster the further out you go.
- **Settings search** finds every Fretboard settings option by its own label.
- **FX window meter:** a track without an audio input shows the MIDI notes it receives in its Input bar.
- **Theme-aware defaults:** the dark theme starts on Rosewood at 75% board brightness and the light theme on Maple at 90%; a look you chose stays. Fretboard inlays show their own material colours, and the capo selector, focus rings, drop previews and active section band follow your accent colour.

## 🛠️ Fixes and performance

- Start-up loudness: the first sound no longer reaches the output without the Monitor FX plug-ins, such as the IR Loader's auto level.
- Start-up crash: the fretboard could fail to draw at start-up because of an inlay colour name mismatch. Fixed.
- Rewinding again while the song is still being prepared no longer restarts the preparation, so the playhead no longer holds still between presses.
- Dragging a selection during playback no longer jumps the view back to the playhead.
- A docked plug-in editor larger than its area now scrolls instead of losing its right and bottom parts, at any interface size.
- Band view side panels come back in the same column and width as in the normal view.
- The Live input strip fits one row at the default window size with no clipped controls.
- Download names include the whole version, for example `TabForge-0.9.1-win-x64-portable.zip`.

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental. Some JUCE 8 plug-in editors can render black under Wine; eight bridged plug-ins may need 1,024-frame buffers. A faulty native 64-bit VST2 plug-in can still crash the Windows audio engine.
