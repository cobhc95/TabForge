# TabForge 0.9.0

Stable maintenance release. It adds no new features: it fixes crash-recovery and shutdown problems and removes a large amount of unused code and files.

## 🎸 New since 0.8.8

- **More complete crash recovery:** a recovered song now keeps its track inputs, Band layout and collapsed mixer groups, and its audio clips still point to the right files.
- **Tidier dialogs:** many windows now share one set of text sizes and corner radii, and more dialog buttons use the same padding.

## 🛠️ Fixes and performance

- If the disk is too slow to finish writing a recording at shutdown, the lost audio is now reported instead of the take silently ending short.
- The audio engine no longer leaves a background timer running when it stops while connecting.
- Shutting down during a stuck render no longer disposes plug-ins that are still in use.
- A failed update check now says so instead of reporting that you are up to date, and a long release list can no longer stop the check working.
- People on 0.8.75 were not offered 0.8.8 because the check read 75 as higher than 8. This release is numbered 0.9.0 so that it reaches them.
- The "Plug-in loading slowly" prompt now closes with its window.
- A plug-in that connects after its timeout no longer leaks a connection.
- The IR Loader editor stops checking for updates while it is hidden.
- Removed unused code, settings and files. Settings files from earlier versions still load.

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental. Some JUCE 8 plug-in editors can render black under Wine; eight bridged plug-ins may need 1,024-frame buffers. A faulty native 64-bit VST2 plug-in can still crash the Windows audio engine. See the [complete changelog](https://github.com/cobhc95/TabForge/blob/v0.9.0/docs/CHANGELOG.md) for all changes, and the [compatibility notes](https://github.com/cobhc95/TabForge/blob/v0.9.0/docs/reference/COMPATIBILITY.md).
