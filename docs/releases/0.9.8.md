# TabForge 0.9.8

Stable release. The MIDI processing window is redesigned and fits at every scale, and the side-panel button is fixed.

## 🔧 Changed

- **MIDI processing window:** processors grouped by what they do, each with an icon, foldable groups and search across all. The chain has drag handles, power switches, drag or Alt+Up/Down to reorder and a right-click menu; the editor shows each section as a card, knobs two per row. Chain presets sit at the top.
- **Fits at every scale:** labels wrap or move above their control instead of being cut off, at any UI scale, density, font or window size.

## 🛠️ Fixes

- **Side-panel button:** it is lit when the panel shows, not the reverse.
- **Faster side-panel toggle:** one layout rebuild instead of one per panel, so it no longer takes one to two seconds.

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental.
