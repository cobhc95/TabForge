# TabForge 0.9.12

Stable release. Fixes a Band view crash and tab peel-off, and lets you hide technique labels on the fretboard. Supersedes 0.9.11.

## ✨ Added

- **Hide technique labels:** Fretboard settings > Note dots > Show technique labels (on by default) hides the hammer-on, pull-off, slide and other tags beside playing notes.

## 🐞 Fixed

- **Band view crash:** small fretboards with Blocks or Trapezoids inlays no longer close TabForge.
- **Tab peel-off:** dragging any tab out of the strip opens it in a new window again.
