# TabForge 0.9.9

Stable release. Adds the note colour legend to Keyboard mode, unifies Fretboard Settings and Global Tuning with the main Settings and Track properties design, and shrinks the Windows download and install footprint.

## ✨ Added

- **Keyboard mode legend:** added the note colour legend to Keyboard mode.

## 🔧 Changed

- **Unified Fretboard Settings:** redesigned to share TabForge Settings' layout chrome, flat square sidebar navigation highlights, `PrefsFieldClass` pull-down menus, colour buttons, and two-column setting rows.
- **Unified Global Tuning:** matched Track properties' tuning card layout with clarified tooltips explaining how all pitched tab tracks are retuned together.
- **Flat sidebar tab highlights:** sidebar navigation highlights across Preferences and Fretboard Settings now use crisp flat square edges with the left accent bar.
- **Scale highlight defaults:** scale highlighting remains off by default and now defaults to `Cell tint` at `35%` opacity when enabled.
- **Smaller Windows download & install:** switched the Windows installer to `lzma2/ultra64` compression and excluded unused runtime debug/GC/HTTP3 binaries and non-Windows Avalonia backends from Windows publishes.
- **Lighter background activity & codebase cleanup:** backed off audio engine liveness polling to 2 s, switched post-open GC to non-blocking optimized mode, consolidated internal architecture docs, and modularized features.

## 🛠️ Fixes

- **Content-sized prompts under UI scaling:** prompt windows sized to their content are no longer stretched when UI scaling is active (`UiScaleRoot`).

Windows installers are not code-signed. Linux has not been validated on real hardware and remains experimental.
