# Keyboard shortcuts quick reference

This page lists the default keys of TabForge, grouped by what you are doing. It shows only the default set. Hover over any button to see its current key in brackets. If you change a key, the brackets follow.

You can change any key in **Preferences > Shortcuts**, as **Chapter 13: Make TabForge yours** shows. Many commands have no default key, and you can give any of them one there. A few editor keys, such as the digits, are fixed. The menus print each key from your current bindings, so a rebind shows there at once.

Key names follow the keyboard. The semicolon key is written `;`, and the other punctuation keys are named in words, such as `Full stop` and `Slash`.

### Try it: Find any key in the command palette

*Goal: look up the key for a command without searching a table.*

1. Press `Ctrl+Shift+A`. The **Command palette** opens with a search box.
2. Type `loop`. The list shows the commands that match, each with its key on the right.
3. Read the key beside **Loop**. Press `Esc` to close the palette. Nothing runs.

You can use the command palette this way for any command, including ones with no default key.

## Quick recap

- This page shows the default keys. Change any of them in **Preferences > Shortcuts**.
- Hover over a button to read its current key in brackets.
- Digits write frets, letters switch on techniques, and the arrow keys move the edit cursor.
- `Ctrl+Shift+A` opens the command palette, which finds any command and its key.
- Some editor keys are fixed, and many commands have no default key.
