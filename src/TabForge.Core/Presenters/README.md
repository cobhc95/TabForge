# Presenters

Window logic that needs no WPF types: the state and commands a window's view drives. The view (in `Source/src/TabForge.Avalonia/Views/`) keeps only layout and wiring.

## Files
| File | Purpose |
| --- | --- |
| `CommandPalettePresenter.cs` | The command palette's entries, fuzzy filter and ranking, selection and chosen command. The view is `Views/CommandPalette.cs`. |
| `PaletteToolCatalog.cs` | The palette tool rows, their tabs and the command each runs. Adding a tool: `../../../docs/guides/ADD_TOOL.md`. |
| `CompactModeStripPresenter.cs` | The compact mode strip's visibility rules, pill tooltip and lit pill. The view is `CompactMode/CompactModeStrip.cs`. |
| `MessageBoxPresenter.cs` | The themed message box's button labels and answers, default, Esc and close answers and icon glyphs. The view is `Views/ThemedMessageBox.cs`. |
| `ImportStatusPresenter.cs` | The status bar text, tooltip and Cancel button text for pending score imports, and the text after a cancelled import. The view is `MainWindow.Import.cs`. |
| `AudioDeviceStatusPresenter.cs` | The status bar's audio device text, tooltip and visibility: the running device with its latency, rate and buffer, or the idle ASIO device. The view is `MainWindow.Clips.cs`. |
| `MidiOutputStatusPresenter.cs` | The status bar's MIDI output name: the device the selected track sends to, or the fallback text. The views are `MainWindow.Tracks.cs` and the Avalonia `StatusBarView`. |
| `KeyboardModePopoutPresenter.cs` | The Keyboard mode pop-out's open rule, texts and full screen keys. The views are `KeyboardMode/KeyboardModePopout.cs` and `KeyboardModePopoutWindow.cs`. |
| `GlobalTuningPresenter.cs` | The global tuning window's six-string tuning: nudges, typed shifts, presets and the matching choice, string note, thickness and offset text. The view is `Views/GlobalTuningWindow.cs`. |
| `SavePromptPresenter.cs` | The save, discard and cancel prompts: the save-changes and after-an-error overwrite texts, and what Yes / No / Cancel mean. The views are `MainWindow.File.cs` and `Controllers/WindowCloseFlow.cs`; saving stays in `DocumentSaveFlow`. |
| `SignatureChoices.cs` | The key-name and time-signature denominator choices shared by the project settings dialog and the standard dialogs, as read-only lists. |
| `PluginApprovalNoticePresenter.cs` | The plug-in approval notice text and tool tip (none when nothing waits). Trust stays in `PluginTrust`, which fails closed. The view is `Controllers/ApprovalNoticeController.cs`. |
| `ProjectSettingsPresenter.cs` | Project settings: the key and denominator choices, tempo and beats checks, the result, the pending-change list and the summary figures. The view is `Views/ProjectSettingsWindow.cs`. |
| `HotkeyEditPresenter.cs` | The Shortcuts page rules: key capture (modifier-only and Esc), gesture text, conflicts across both slots, reassign, clear, reset, the customized mark. Used by `Views/Preferences/HotkeyPage.cs` and `TabForge.Avalonia/Views/ShortcutsPage.cs`. |
| `ClipGesturePresenter.cs` | The timeline clip gesture rules: gesture under a press (body, trim edges, fade handles), click jitter, nearest snap candidate, lane and notation-row under a dragged clip, cancelled-trim restore, and the waveform span and peak range. The views are `Views/ClipGestureController.cs` and `Views/TrackTimeline.Waveform.cs`. |
| `ColourChooserPresenter.cs` | The colour chooser's colour (RGBA), preset rows, matching preset, hex text and slider conversions. The view is `Views/ColourChooser.cs`. |
| `SectionDragPresenter.cs` | The timeline section lane's hit lookup, drop slot, packed drag preview layout and per-frame easing step. The view is `Views/TrackTimeline.Interaction.cs`. |
| `ArrangementRowPresenter.cs` | The track list's row geometry (group runs, row top, row and header at a y, rows height) over an `IArrangementRowSource`. The view is `Views/ArrangementPanel.RowGeometry.cs`. |
| `TrackReorderPresenter.cs` | The track drag preview maths (row offsets, drawn-lane order, per-frame easing). The view is `Views/TrackTimeline.cs`. |
| `TrackIconKeys.cs` | The GM program to track-row icon key mapping, shared by the WPF `TrackSilhouette` and the Avalonia `TrackIconArt`. |
| `BandReorderPresenter.cs` | The Band view's row-drag maths (drop index, slot top, glide offset, edge scroll step, row height clamp). The views are `Views/Band/BandReorder.cs` and `BandView.cs`. |
| `MasterLaneRules.cs` | The master track lane's row count, height, line height and gap, and the strip hit rule. The views are `Views/MasterLane/MasterLane.cs` and `TrackTimeline.MasterLane.cs`. |
| `FretboardGeometryRules.cs` | The fretboard layout (board rectangle, visible fret window, string gap), string and fret positions and the click-to-fret hit test. The WPF face is `Visualization/FretboardGeometry.cs`. |
| `KeyboardGeometryRules.cs` | The keyboard key range per size, the octave shift that follows sounding notes, white and black key rectangles and the click-to-key hit test. |
| `KeyboardPaneSizeRules.cs` | The keyboard pane's height rule: the natural key height from the white key width (60-120 DIPs), the pane's min and width-limited max height, and the white key count per size. |
| `PercussionKeyMapRules.cs` | The drum key map maths (GM names 27-87, columns, cell rects, click-to-note hit test, labels, glow fade, required height); drawn by the WPF `InstrumentPanel.Percussion` and the Avalonia `InstrumentPanelView`. |
| `InstrumentLitNotes.cs` | The notes an instrument panel lights for a score cursor: the string, fret and MIDI note of each sounding note in one beat cell. The view is the Avalonia `InstrumentPanelView`. |
| `ConfirmDialogPresenter.cs` | The confirm prompt's button tooltips and key hints, "Show changes" link, remember tooltip, scope heading and width. The views are `Views/ThemedConfirmDialog.cs` and the Avalonia `SavePromptWindow` / `BarRangePromptWindow`. |
| `BarRangePromptPresenter.cs` | The Delete-bars prompt's title, buttons, option labels with shortcuts, scopes, defaults and `BarRangeAnswer`. The view is `Views/BarRangePrompt.cs`. |
| `PasteOptionsPresenter.cs` | The combined paste dialog's question order, option labels, words and answers. The view is `Views/PasteOptionsDialog.cs`. |
| `PasteSpecialPresenter.cs` | Paste Special's repeat, mode, octave shift, check boxes and the `PasteSpecialOptions` they make. The view is `Views/PasteSpecialDialog.cs`. |
| `ScoreTextStylePresenter.cs` | The score text style window: the seven text areas, the style each one edits, the values its rows show and the rules that write a change back. The view is `Views/ScoreTextStyleWindow.cs`. |
| `TabStripPresenter.cs` | The document tab strip rules: tab width range, close-button mode, corner radius and the drop index among tab centres. Views: `Views/BrowserTabBar.xaml.cs` and the Avalonia `TabStripView`. |
| `ViewTempoBarPresenter.cs` | The View and tempo bar texts: button names, tooltips, captions from the values and the full key name. Views: `Views/ViewTempo/ViewTempoBar.cs` and the Avalonia `ViewTempoBarView`. |
| `TunerPresenter.cs` | The tuner's reading rules without UI types: which readings count, the smoothing within a note, the note name and Hz and cents text, the needle position and in-tune tone, and the string closest to the sound. The view is `Views/TunerWindow.cs`. |
| `PromptTextsPresenter.cs` | The small track and confirm prompts (Add track, Delete track, Convert to audio, Convert to instrument clips, Change instrument, Confirm): title, message, buttons, Enter default, choices, remember box, the Undo sentence, and the answer mapping (`PromptAnswer`, `AddTrackChoice`, `ClipAnswer`). The WPF view is `Views/ConfirmPrompt.cs`; the Avalonia window is `TabForge.Avalonia/Views/PromptWindow.cs`. |
| `WiringPresenter.cs` | The Wiring window's logic: the pin, MIDI source, channel and track choices with their labels, the disabled reasons, the selections, the loop check for sidechain and MIDI-forward links, and the window's texts. The views are `Views/WiringWindow.cs` and `Source/src/TabForge.Avalonia/Views/WiringWindow.cs`. |
| `UpdateAvailablePresenter.cs` | The "update available" and "up to date" window: its title, heading and detail texts, the opt-out box, the privacy line, and which buttons exist with which is the default. The views are `Views/UpdateAvailableWindow.cs` and `TabForge.Avalonia/Views/UpdateAvailableWindow.cs`. |
| `QuarantinePresenter.cs` | The "Plug-ins switched off after a crash" window: its title and caption, the rows (file name shown, full path as tool tip) and the empty-list text. The views are `Views/QuarantineWindow.cs` and `TabForge.Avalonia/Views/QuarantineWindow.cs`; trust and the allow-again rule stay in the app. |
| `ColourPickerPresenter.cs` | The colour picker popup: ready-made and recent colours (and keeping the recent list), the colour being chosen, whether it can be see-through, square / hue / opacity positions, the code text and its message, and the Use and Default texts. The view is `Views/ColourPickerPopup.cs`. |
| `PluginBrowserListPresenter.cs` | The Add plug-in list: known vendor and role merge, filter, sort, row text, status line and the common-folder merge. The view is `Views/PluginBrowserDialog.cs`. |
| `TrackColoursPresenter.cs` | The Colour tracks dialog's tick state, range ticking and the colouring of the ticked rows. The view is `Views/Timeline/TrackColoursDialog.cs`. |
| `StandardDialogsPresenter.cs` | The standard dialogs' scope texts, direction names, marker colours and input parsing. The view is `GpDialogs.cs`. |
| `PresetManagePresenter.cs` | The preset manage panel's rules without UI types: the plan of an inline rename (the name error, same name, the preset a rename would replace) and the block moves of chosen presets. The view is `Views/Presets/PresetManagePanel.cs`. |
| `DrumMapDraftPresenter.cs` | The drum map editor's checks: the draft of one map from the editor's rows and its messages, and pairing a note by piece name. The view is `Views/NoteMaps/DrumMapEditorWindow.cs`. |
| `EffectValuesPresenter.cs` | The value-based effect editors' preset row labels, Delete preset rule, save-failure text and setting fallbacks. The views are `Views/EffectEditors/ValuesEffectDialog.cs` and `OrnamentEditors.cs`. |
| `MixTablePresenter.cs` | The Mix Table window's rules: the field ranges and start values, the instrument and Transition choices, the tempo parse, the texts, and the result of OK and Clear. The view is `Views/MixTableWindow.cs`; the write to the beat stays in `MainWindow.ContextMenus.cs`. |
| `MidiProcessingListPresenter.cs` | The MIDI processing window's processor list rules: the 32-processor cap, where a new or moved processor goes, the enabled Up, Down and Remove buttons, the row labels and the detail texts when no known processor is selected. The view is `Views/MidiProcessingWindow.cs`; the chain and the engine stay there. |
| `PreferencesPagePresenter.cs` | The Preferences window's page rules: the cards of a page or a search (order, captions, Basic and More rows), the enabled rule of dependent rows, the reset texts and the pending-change list. The view is `Views/PreferencesWindow.xaml.cs`; rows stay in `SettingsCatalog`, saving and migration in `SettingsMigration`. |
| `MixerStripPresenter.cs` | The Mixer strip rules without WPF types: the pan range text, the semitone text, the MIDI sound box rule, a strip name with its mute and solo state, and the no-tracks message. The view is `Views/MixerWindow.cs`. |
| `FxChainPresenter.cs` | The FX chain window's title, notices and CPU status text, the bypass overlay and Remove rules, and when the GM sound plays again. The view is `Views/FxChainWindow.cs` (its sections are in `Views/FxChainWindow.Sections.cs`); the chain, the trust check and the engine stay there. |
| `GroupRulesPresenter.cs` | The Group rules editor's rules without UI types: the groups being edited with their open-time names, the fallback name, the add, move, delete, rename, colour and rule edits, the rule type defaults, the value choices and hints, and the check of OK (the result or the problem). The view is `Views/GroupRulesDialog.cs`; applying the result stays in `MixerWindow.Groups.cs` and `MixerRules`. |
| `DockPanePresenter.cs` | The dock panes' solo rule (tab strip hidden when alone), which panes can move, float and close, the tab tool tip, the floating-window title and the pane menu entries. Titles and tab order stay in `Docking/DockPaneTable.cs`; drag, drop and window placement stay in the views `Views/DockWorkspace.cs` and `Docking/DockViews.cs`. |
| `MainSettingsFlow.cs` | The order the main window applies settings in (`MainSettingsStep`), which steps one apply runs (window size only at load, audio route on request) and which redraw on a visual change. What each step applies stays in the window's appliers (subscribed to `MainWindowSettings.SettingsChanged` in `MainWindow.Compose.cs`). |
| `ScoreEditorGeometry.cs` | The score editor's page arithmetic: system, staff and TAB tops, scroll offsets for a bar, bar slots and the in-bar cell clamp. The view is `Views/TabEditorControl.Geometry.cs`. |
| `PresetDeleteQuestionPresenter.cs` | The words of the question before presets are deleted: the text for one preset or several (up to five names), and the "Don't ask again" check box text. |
| `PresetRules.cs` | The naming rules every preset kind shares: the name check and the copy name. |
| `MainMenuTable.cs` | The plain main-menu rows as data: each menu group's menu and anchor, the captions, command ids, tags and separators. The handlers are bound in `MainWindow.Menus.cs`; the WPF build is `Views/MainMenu/MenuTable.cs`. |
| `LegacyGpPreflightPresenter.cs` | The question before a copy for older programs (.gp5 / .gp4 / .gp3) is written: title, headline, intro, advice, list text and the Save copy / Cancel buttons. The view is the second constructor of `Views/GpExportPreflightWindow.cs`. |
| `GpExportPreflightPresenter.cs` | The export preflight window's title, headline, intro, advice, list text and its three buttons (labels, choice, default and Esc roles) for a Save or an Export. The view is `Views/GpExportPreflightDialog.cs`. |
| `TrackOutputPresenter.cs` | The MIDI output window's title, button labels, track heading and hint, and the rule that only a selected device id is a choice. The view is `Views/Timeline/TrackOutputWindow.cs`. |
| `TrackPropertiesPresenter.cs` | The track properties rules both track editors share: title, field checks and texts, the name rule, the channel an instrument leaves, the string tools and the quick editor's write. The views are `Views/Timeline/TrackPropertiesDialog.cs` and `GpDialogs.cs`. |
| `RenderDialogPresenter.cs` | The File > Render dialog's option lists, format and sample-rate rules (MP3 takes 44.1 / 48 kHz), bounds rules, hint texts and the output file names a render writes. Not yet wired: the view is `Views/RenderWindow.cs`, which still holds this logic. |
| `VideoExportPresenter.cs` | The video export window's option lists and their defaults, the remembered settings it loads and saves, the track checks, the enabled rules, the range problems, the save dialog's name and folder, and the status texts. The view is `Views/VideoExportWindow.cs`; encoding stays in `Services/Video`. |
| `TutorialPresenter.cs` | The Help > Tutorial window's rules: the guide title and choice (Detailed falls back to Basic), the contents rows, the Back, Forward, Previous and Next enabled states, the empty-library state, the search panels and the PDF export's progress and result texts. The view is `Views/TutorialWindow.xaml.cs`; the PDF writer stays in `Views/TutorialPdfExporter.cs`. |
| `TutorialHistory.cs` | The tutorial reader's Back and Forward history: the visit rules and the step bounds. The view is `Views/TutorialWindow.xaml.cs`. |
| `WindowTitlePresenter.cs` | The main window title text: "TabForge - {song}" with the unsaved marker and the degraded-mode suffix. The view is `MainWindow.Keyboard.cs` (`UpdateTitle`). |
| `TitleMarkers.cs` | The unsaved marker, the never-saved note and the degraded-mode suffix. The window title uses the marker and suffix; the tab tooltip and the song stats heading use the note. |
| `TabLabelPresenter.cs` | The document tab name (file name, else song title, else "Untitled") and tooltip (path, or the name plus the unsaved note). `SongDocument` delegates its `DisplayName` and `Tooltip` here. |
| `ScoreCursorNavigator.cs` | The score editor's cursor-move rules (beat, bar, string, bar end, last bar, entered note, song end) over an `IBarCursorStops`. The view applies the target and raises the events in `Views/TabEditorControl.Navigation.cs`. |
| `ScoreCursorText.cs` | The score editor's spoken texts for screen readers (cursor, beat, read position, read bar). The automation peer and the announcement change tracking stay in `Views/Score/EditorAutomation.cs`. |
| `ScoreSelectionRules.cs` | The score editor's selection rules: clamping a requested range to the track, ordering a range, the select-all range and range matching. The view is `Views/TabEditorControl.Selection.cs`; the selection state and its snapping stay in `Score/EditorSelectionState.cs`. |
| `ScoreEditToolState.cs` | The score editor's tool state: current duration, dots, tuplet, entry velocity and entry flags, with the merge-rests rule. The view forwards to it from `Views/TabEditorControl.cs`; the edits are in `Score/Editing/ScoreEditCommands.cs`. |
