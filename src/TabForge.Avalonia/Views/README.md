# TabForge.Avalonia views

- Owns: the Avalonia twins of WPF windows, each driven only by its Core presenter.
- Does not own: logic (Core presenters) or adapters (`Source/src/TabForge.Avalonia/Platform`).
- Tests: the headless test project (`dotnet test`).
