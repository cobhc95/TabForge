# TabForge.Avalonia shell

- Owns: the window shell parts of the Avalonia preview: the title row and its caption buttons, the title bar's contract with the native hit test, and (in `Win32/`) the Windows window-procedure hook and window actions.
- Does not own: the chrome hit rules (`Source/src/TabForge.Core/Shell/ChromeHitRules.cs`), the plain window actions (`Source/src/TabForge.Avalonia/Platform/AvaloniaWindowChrome.cs`), the tabs (`Source/src/TabForge.Avalonia/Views/TabStripView.cs`) or feature views (`Source/src/TabForge.Avalonia/Views`).
- Tests: the headless test project (`dotnet test`), `TitleBarTests`, `TitleBarRectsTests`, `NcHitTestHookTests`, `TabTearOffTests`.

| File | Owns |
|---|---|
| `Source/src/TabForge.Avalonia/Shell/TitleBarView.cs` | The 44 px title row, the twin of the WPF `TitleBar`: tab strip on the left, caption buttons on the right. A press on the empty caption starts the move, a double-click toggles maximise. `For` sets the extended client area (no system chrome, 44 px). The Record and Settings buttons open the preview's Export video and Settings windows. |
| `Source/src/TabForge.Avalonia/Shell/CaptionButtons.cs` | Record, Settings, Minimise, Maximise (Restore when maximised) and Close, with the WPF glyph geometries, widths (40, 40, 46, 46, 46) and the `ChromeCaptionButton` / `ChromeCloseButton` looks. |
| `Source/src/TabForge.Avalonia/Shell/ICaptionButtonRects.cs` | What a title bar tells the native hit test (caption buttons, tabs, tab actions, caption) and how it shows a native hover or press. |
| `Source/src/TabForge.Avalonia/Shell/Win32/NcHitTestHook.cs` | WM_NCHITTEST from `ChromeHitRules` (resize edges 6 DIP, caption buttons for Snap Layouts, caption as HTCAPTION, client), native caption-button hover, press and click; attached by `MainWindowLifetime`, removed on close. |
| `Source/src/TabForge.Avalonia/Shell/Win32/WindowsChromeAdapter.cs` | `IWindowChrome` over an Avalonia window on Windows (state, minimise, maximise, close, native move and resize drags). |
| `Source/src/TabForge.Avalonia/Shell/WindowChromeFactory.cs` | The one place that picks the window chrome: `WindowsChromeAdapter` on Windows, `AvaloniaWindowChrome` elsewhere. `TitleBarView` implements `ICaptionButtonRects` from its live layout; a native press suppresses the Avalonia click so a button acts once. |
| `Source/src/TabForge.Avalonia/Shell/DragSession.cs` | The state of one tab drag shared by the document and dock flows: the dragged tab, the Escape cancel until release, and the drop check (a cancelled drag drops nothing). Tests: `TabTearOffTests`. |
| `Source/src/TabForge.Avalonia/Shell/DocumentTabDragFlow.cs` | A song tab dragged live: beyond the `TabDragRules` tear-off band a new window holds the song and follows the pointer (a lone tab moves its window); the drop preview shows on the strip under the pointer; release merges into that strip at the insertion slot, gives the song back to its own strip, or keeps the new window; in-strip drags reorder with neighbours sliding; Escape gives the song back. Tests: `TabTearOffTests`, `TabDragRulesTests`. |
| `Source/src/TabForge.Avalonia/Shell/DocumentTabLiveTearOff.cs` | The window that follows the pointer during a live tear-off (a new window holding a copy of the song, or the lone source window): keeps the grabbed point under the pointer, goes translucent over another strip, and reverts or closes its copy. Tests: `TabTearOffTests`. |
| `Source/src/TabForge.Avalonia/Shell/AppServices.cs` | The services every window shares (plug-in trust, shared meter tick), made once when the first window is composed; `TabWindowRegistry` holds them. |
| `Source/src/TabForge.Avalonia/Shell/TabWindowRegistry.cs` | The open main windows tab drags move between (added when made, removed when closed) and whose strip lies under a screen point (`TabDragRules.ResolveDropTarget`, newest window first). |
| `Source/src/TabForge.Avalonia/Shell/MacChromeAdapter.cs` | macOS: keeps the system traffic lights (system chrome, thick title bar); the title row hides its Minimise, Maximise and Close and starts the tabs after `ChromeHitRules.LeadingInset` (none in full screen). |
| `Source/src/TabForge.Avalonia/Shell/LinuxChromeAdapter.cs` | Linux client-side decorations: eight 6 DIP resize grips that call `BeginResize`, a 1 px palette border, both hidden unless the window is normal. |
